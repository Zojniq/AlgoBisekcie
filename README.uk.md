# Чисельний метод бісекції

[English version](README.md)

Реалізація чисельного **методу бісекції (поділу відрізка навпіл)** мовою Java для знаходження дійсних коренів неперервної функції.

## Опис задачі

За замовчуванням програма розв'язує рівняння:

$$f(x) = x - \cos(x) = 0$$

Програма:

1. Зчитує пари значень $(x, f(x))$ із файлу `data.txt`.
2. Знаходить початковий інтервал, на якому функція змінює знак.
3. Послідовно ділить інтервал навпіл.
4. Завершує обчислення, коли довжина інтервалу відповідає заданій точності `epsilon`.

## Універсальність алгоритму

Програму можна адаптувати для будь-якої неперервної функції, для якої відомий відрізок зі зміною знака функції.

### 1. Змініть формулу функції

Оновіть метод `f(double x)` у класі `Main`:

```java
// Приклад 1: многочлен x^3 - x - 2 = 0
static double f(double x) {
    return Math.pow(x, 3) - x - 2;
}

// Приклад 2: рівняння exp(-x) - x = 0
static double f(double x) {
    return Math.exp(-x) - x;
}
```

### 2. Оновіть `data.txt`

Замініть вміст файлу `data.txt` на нову таблицю точок для вибраної функції. Програма автоматично знайде сусідні точки, між якими функція змінює знак.

> **Важливо:** функція повинна бути неперервною на вибраному відрізку. Наприклад, для функції $f(x) = \frac{1}{x}$ не можна застосовувати метод бісекції на відрізку, що містить точку `x = 0`.

## Формат вхідних даних

Файл `data.txt` повинен містити пари чисел, розділені пробілом або табуляцією:

```text
0.5 -0.377583
0.6 -0.225336
0.7 -0.064842
0.8 0.103293
0.9 0.278390
1.0 0.459698
```
